# Nxt Trendz

An e-commerce web app built with React where users can log in, browse products, add them to a cart and place an order.

**Live Demo:** https://nxt-trendz-gamma-three.vercel.app

**Demo login:** username `rahul` | password `rahul@2021`

## Features
- Login with authentication (token stored in cookies) and protected routes
- Product listing with search, sorting and category/rating filters
- Product details page
- Cart with add, remove and quantity update
- Checkout payment popup with payment options, order summary and order confirmation message
- Loading spinners and error/empty states

## Tech Stack
- React.js 17
- React Router v5
- CSS
- reactjs-popup, react-icons, react-loader-spinner, js-cookie

## Run Locally
```bash
git clone https://github.com/Anugrahasakthi/Nxt-Trendz.git
cd Nxt-Trendz
npm install --legacy-peer-deps
npm start
```
The app opens at http://localhost:3000
